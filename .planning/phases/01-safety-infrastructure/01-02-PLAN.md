    1. Create `src/safety/pid-registry.ts`:

       ```typescript
       export interface PidEntry {
         pid: number;
         storyId: string;
         startedAt: string;
       }
       ```

       Functions:
       - `readRegistry(workspaceDir: string): PidEntry[]` — reads `pid-registry.json` from workspaceDir. Returns `[]` if file missing or unparseable.
       - `registerPid(workspaceDir: string, storyId: string, pid: number): void` — appends entry with `startedAt: new Date().toISOString()`. Uses synchronous fs (fine for registry — one write per spawn, parent process only).
       - `deregisterPid(workspaceDir: string, pid: number): void` — removes entry by pid. Deletes file if result is empty array.
       - `isProcessAlive(pid: number): boolean` — `try { process.kill(pid, 0); return true; } catch { return false; }`
       - `cleanupOrphans(workspaceDir: string, statePath: string): void` — reads registry, finds entries where `isProcessAlive` returns false, marks their stories as 'interrupted' via `markStoryInterrupted` from tracker, deregisters dead PIDs, logs `[william] Cleaned up stale PID registry from previous run (N orphaned PID(s)).` Uses `saveState` (not locked) here because cleanup runs at startup before any concurrent access.

    2. Create `src/safety/shutdown.ts`:

       ```typescript
       export interface ShutdownOptions {
         workspaceDir: string;
         onExit?: (code: number) => void;  // Defaults to process.exit; injectable for testing
       }
       ```

       Module-level state:
       - `let shuttingDown = false;`
       - `let registeredWorkspaceDir: string | null = null;`

       Functions:
       - `registerShutdownHandlers(options: ShutdownOptions): void` — registers handlers for SIGINT, SIGTERM, and SIGHUP. Stores workspaceDir in module scope. The handler calls `gracefulShutdown(signal, options)`.
       - `gracefulShutdown(signal: string, options: ShutdownOptions): Promise<void>`:
         - If `shuttingDown` is already true (double Ctrl+C): log `[william] Force shutdown requested. Killing all agents immediately...`, SIGKILL all alive PIDs from registry, call `onExit(1)`.
         - Set `shuttingDown = true`.
         - Read registry, filter to alive processes.
         - SIGTERM each alive process. Catch errors (already dead).
         - `await` a 5-second timeout (`new Promise(resolve => setTimeout(resolve, 5000))`).
         - Check survivors: for each still alive, SIGKILL and log `[william] Agent [${storyId}] did not respond to graceful shutdown, force-killed.`
         - Log summary: `[william] Shutting down... killed ${count} agent(s), state saved.`
         - Call `onExit(signal === 'SIGINT' ? 130 : 143)`.
       - `killAllAgents(workspaceDir: string): void` — reads registry, SIGTERMs all alive PIDs. For use in `william stop`. Logs count of killed agents.
       - `resetShutdownState(): void` — resets `shuttingDown` to false and `registeredWorkspaceDir` to null. Exported for testing only.
