    Create `src/prd/dependency-analyzer.ts` with these exports:

    ```typescript
    export interface StoryDependency {
      storyId: string;      // must complete first
      dependentId: string;  // depends on storyId
      reason: string;       // human-readable
      confidence: 'explicit' | 'semantic' | 'phase-order';
    }

    export interface ExecutionGraph {
      order: string[];           // topological order
      parallelGroups: string[][]; // stories at same depth
      cycles: string[][];        // cycle paths (empty = no cycles)
    }

    export function inferDependencies(stories: ParsedStory[]): StoryDependency[];
    export function buildExecutionGraph(stories: ParsedStory[], deps: StoryDependency[]): ExecutionGraph;
    export function formatDependencyReport(stories: ParsedStory[], graph: ExecutionGraph, deps: StoryDependency[]): string;
    ```

    `inferDependencies` implementation:
    - Run all three heuristics, collect edges, deduplicate by (storyId, dependentId) keeping highest-confidence edge (explicit > semantic > phase-order).
    - Heuristic 1 (Explicit ID): For each story, check if text (title + description + acceptanceCriteria joined) contains another story's ID using word-boundary regex. Skip self-references. Edge direction: mentioned story -> mentioning story.
    - Heuristic 2 (Semantic Keywords): Match dependency phrases (requires, depends on, after X complete, builds on, uses X from) against other story titles using case-insensitive substring matching. Edge direction: referenced story -> referencing story.
    - Heuristic 3 (Phase-Group): Group stories by phaseGroup. For each consecutive pair of groups, add edge from last story of earlier group to first story of later group. confidence: 'phase-order'.

    `buildExecutionGraph` implementation:
    - Kahn's algorithm (~60 lines). Build adjacency list and in-degree map from deps. BFS wave-by-wave: all nodes with in-degree 0 form current wave (parallelGroups entry). Process each wave, decrement neighbors' in-degree, collect next wave. After BFS, any nodes not in order are cycle nodes. For cycle detection, run DFS on the subgraph of cycle nodes to reconstruct at least one cycle path.

    `formatDependencyReport` implementation:
    - Returns a string (NOT console.log -- pure function, caller prints). If cycles: return error string with cycle path. If zero deps: return "No dependencies inferred -- all stories are independent." Otherwise: for each parallel group, list "Ready:" stories (no deps) and "Blocked:" stories (with deps, showing blocker IDs).

    IMPORTANT: `formatDependencyReport` must return a string, not call `process.exit()`. The caller in workspace.ts will handle exit logic. This keeps the module pure and testable.
